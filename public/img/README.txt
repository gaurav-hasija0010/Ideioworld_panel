Put your Ideioworld logo here.

Save the logo image as:   logo.png   (in this folder: public/img/logo.png)

Once the file exists, the app automatically shows it in the sidebar and on the
login screen in place of the built-in "ideioworld" wordmark. No code changes
needed — just drop the file in and refresh the page.

Recommended: a PNG with a transparent background, around 200–320px tall.
